## 〇、赛规核实记录（以本节为准，修订前文任何冲突表述）

1. **平台合规性**：赛题 1.1 为"**推荐**选用平台 1：HX4S20C"（推荐而非强制）；1.2/1.3 的硬性表述为"在基于**安路 EG4S 系列**芯片的 FPGA 开发平台上"、"以安路科技 EG4S20BG256 器件作为核心平台"。自购 DMZ-EG4S20 底板核心器件即为 EG4S20BG256 → **字面合规**。风险控制：向指导老师/主办方报备"使用自购 EG4S20BG256 平台"并获得认可（进行中，不阻塞开发）。
2. **官方例程基线（重要）**：赛规 p.5 明示官方例程 `lab_ex_5` = "SD/TF 卡存储 **640×480 24 位非压缩 BMP** 图片，读取至 SDRAM 中，通过 HDMI 显示，支持按键手动切图、自动轮播及 **HDMI 音频输出**测试音"。→ 本项目 A 级基线分辨率、图片规格、交互均与官方例程对齐：**640×480 基线分辨率、24bit 非压缩 BMP**；片内 SDRAM 2M×32bit 容量充分（RGB565 单帧 ≈0.59MB）。
3. **评分标准（1.5）**：基础 4 项 = 核心功能完整性 / 显示稳定性与鲁棒性 / **基础音频输出** / 系统工程规范性。扩展 5 项 = ①图层叠加与字幕 ②图片轮播与转场特效 ③图片自适应缩放 ④实时参数调节与 OSD ⑤音频可视化。分值导向：稳定完成 1 项获一定分值；**2 项且效果良好获扩展部分一半以上**；3 项完成度高获较高分。→ 扩展目标定为 **B1+B2 稳定、B3+ 力争**（与 README 阶段六一致）。
4. **自备设备（1.6，现场演示）**：三选一——(1) HDMI 音视频显示器/电视；(2) HDMI 显示器+外接音箱；(3) HDMI 转 VGA+音频转接器+VGA 显示器+音箱。→ **现场仅一根 HDMI 线出画面**，音频若走板载/声卡需现场另接喇叭；**HDMI 音频输出（lab_ex_5 已验证路径）应作为音频方案首选候选**，至少作为演示模式支持。
5. **"不得带额外处理器"边界**：允许"根据作品需要搭配外围电路或成品模块"。板载 DAP-Link 下载器/USB-UART 芯片属板卡标配调试电路，不参与任何算法/控制数据处理，不违规；**任何形式的数据处理、格式转换、控制流都不得借助任何非 FPGA 处理器**。
6. **多板扩展**：允许"多块同款 FPGA 板卡构建主从结构"，本项目保持单板。

## 一、赛题硬性要求（赛题原文）

1. 基于 EG4S 系列 FPGA 平台（EG4S20BG256：19,600 LUT / 19,600 DFF、
   片上 SDRAM 2M×32bit、4 PLL、16 全局时钟、最多 193 用户 IO）。
2. 以音视频融合的多媒体应用为方向，具有明确应用场景。
3. 体现 FPGA 并行处理、实时控制、低延迟显示、音画同步、多源信息融合优势。
4. 所有算法、控制逻辑及数据处理流程在 FPGA 中自主编程实现。
5. 允许搭配外围电路或成品模块，但**不得带额外处理器**。
6. 允许多块同款 FPGA 板卡主从结构（本团队当前采用单板方案）。

## 二、基础评分要求（赛题原文 1.5 基础要求）

1. 核心功能完整性
2. 显示稳定性与鲁棒性
3. 基础音频输出
4. 系统工程规范性

## 三、扩展评分项（赛题原文 1.5 扩展要求，不强制，基础稳定后实施）

1. 图层叠加与字幕效果
2. 图片轮播与转场特效
3. 图片自适应缩放显示
4. 实时参数调节与 OSD 信息叠加
5. 音频可视化展示

评分导向：稳定完成 1 项获一定分值；2 项且效果良好获扩展部分一半以上；
3 项及以上完成度高获较高分；完成度高、创新性突出可获满分或接近满分。

## 四、本项目功能分级

### A 级（最低交付基线，对齐赛规 1.3 + 官方 lab_ex_5）

| # | 功能 | 说明 |
|---|------|------|
| A1 | 系统启动流程 | 复位→时钟锁定→存储器初始化→视频初始化→启动页→日常模式 |
| A2 | 本地资源读取 | SD 卡（底板 SDIO）读取图片+音频；文件系统与格式细节【待确认：底板原理图 + 官方 SD 例程】 |
| A3 | HDMI 视频显示 | 稳定输出、图片切换、状态显示、异常提示；**基线 640×480**（对齐 lab_ex_5），时序参数【待确认：官方 HDMI 例程 + 底板 P3 脚位】 |
| A4 | 基础音频输出 | 播放/停止/开关；优先评估 **HDMI 音频输出**（lab_ex_5 路径）与板载/ES8388 音频，采样参数【待确认：以官方音频例程为准】 |
| A5 | 按键交互 | 上一张/下一张/播放暂停/模式/音频/参数（4×4 矩阵键 16 键，拨码在插声卡时不可用）；键号【已确认，见 pending_confirmations 第 6 节】 |
| A6 | 日常播放模式 | 校园通知、活动、科普内容轮播 + 编号/状态显示 |
| A7 | 应急信息模式 | 触发后停止轮播→高优先级页面→应急字幕→提示音→保持/退出 |
| A8 | 错误状态提示 | 资源缺失/格式不支持/读取失败时有可见提示，不挂死 |
| A9 | 稳定运行 | 长时间运行无花屏、无死机、按键响应正常 |

### B 级（优先扩展，对应赛题扩展 1/2/4）

| # | 功能 | 说明 |
|---|------|------|
| B1 | 图层叠加与字幕 | 标题、页面序号、播放状态、动态计数/滚动标语 |
| B2 | 图片转场 | 首选淡入淡出（移位近似混合），备选左右/上下滑动 |
| B3 | 实时参数调节与 OSD | 按键/开关调亮度、播放速度等，画面同步显示参数 |

### C 级（次级扩展，对应赛题扩展 3/5）

| # | 功能 | 说明 |
|---|------|------|
| C1 | 音频可视化 | FPGA 内部实时生成音量柱/波形/简易频谱，叠加于画面 |
| C2 | 图片自适应缩放 | 不同分辨率图片缩放适配 HDMI 输出 |

## 五、应用场景定义

**智播校园：校园多媒体信息发布与应急提示终端**

部署对象：校园大厅、教学楼、实验室信息屏。

- 模式 1 日常信息：通知/宣传/科普轮播，背景音频
- 模式 2 科普展示：FPGA 与数字系统科普页面
- 模式 3 应急发布：高优先级应急页面 + 提示音（演示定位，非安全认证设备）

## 六、验收标准

### 基础功能验收

1. 冷启动后自动进入播放界面，HDMI 稳定锁定；
2. 多张预置图片可连续播放，手动切换与自动轮播正常；
3. 长时间运行无死机、花屏、明显闪烁；
4. 错误卡/缺图/不支持格式给出提示而非挂死；
5. 音频输出稳定，与播放状态联动；
6. 应急模式可触发、可退出；
7. 现场操作步骤可重复，断电重启后按预期启动。

### 扩展功能验收（每项）

1. 功能确实运行在 FPGA 内部；
2. 现场可直观看到效果；
3. 基础功能不因扩展失效；
4. 有明确模块划分和验证记录；
5. 能说明资源、时序和稳定性影响。
