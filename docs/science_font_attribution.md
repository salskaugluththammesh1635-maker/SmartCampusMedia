# 科普页字形来源

`rtl/video/science_font16.v` 中的 16×16 点阵字形由系统安装的 **Noto Sans SC Bold** 生成后固化为 Verilog ROM。Noto Sans SC 以 SIL Open Font License 1.1 发布；本工程只分发生成后的点阵数据，不在运行时加载字体文件。

字体项目与许可证：

- [Google Fonts Noto Sans SC](https://fonts.google.com/specimen/Noto+Sans+SC)
- [SIL Open Font License 1.1](https://scripts.sil.org/OFL)
- The license text is included in [`OFL-NotoSansSC.txt`](OFL-NotoSansSC.txt).
